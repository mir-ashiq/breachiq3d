# Demo video storyboard — 165 s (rule: under 3 minutes)

Platform: **public YouTube** (the rules require a public YouTube link —
never Vimeo, never unlisted). Target 165 s, hard cutoff 175 s, checked with
`scripts/check_video.py` before upload.

## Audio

- USB mic, treated room; record voiceover separately from screen capture.
- Waveform QC pass: no clipping, no room echo, consistent levels.
- Music: **original or CC0 only** (rule: no unauthorized music/trademarks);
  keep it −18 dB under the voice with **duck** automation so it never
  drowns the narration.
- Energy: record an "energy pass" — re-read the script 20% louder/faster
  than feels natural; punch up weak verbs before the final take.

## Accessibility & verification

- **Caption** track uploaded with the video (also widens silent viewing).
- The video must show the **live app** — screen recordings, not slides;
  slides only in the 20 s hook.
- Upload checklist: duration check passed → public visibility → **incognito**
  session verification → link re-verified in week 8 before submission.
- Three full **rehearsal** passes + one recorded dry run before the final
  take; the dry run gets reviewed against this timecode table.
